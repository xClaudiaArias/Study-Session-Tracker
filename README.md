# Study-Session-Tracker

small full-stack app where a signed-in user logs study sessions

## Project Scope

React frontend, Express API, PostgreSQL database (Prisma or plain SQL).
Register and log in with JWT. Users only ever see their own sessions.
Create, edit, delete, and list sessions (subject, minutes, date, notes). Filter by week.
Validate input on the server and show clear errors on the client.
Show a weekly total and a simple chart of minutes per subject.
At least 3 automated tests, a README with setup steps, and a live deploy link.
